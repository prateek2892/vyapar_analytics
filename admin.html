How content updates reach your live site.
How publishing works:
1. Make your edits in any section and save them.
2. Click Download content.json below.
3. Go to your GitHub repository → find content.json → upload/replace it with the downloaded file.
4. GitHub Pages will redeploy in ~1 minute. Your live site is updated!
